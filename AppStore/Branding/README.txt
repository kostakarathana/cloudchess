CloudChess app identity — build 5

The source artwork is cloudchess-infinity-master.png. The shipping icon is the 1024×1024 opaque RGB export in cloudchess-icon-1024.png, copied to CloudChess/Assets.xcassets/AppIcon.appiconset/AppIcon.png. iOS supplies the corner mask.

The icon is generated using the saved icon-prompt.txt. scripts/draw_icon.swift is the historical icon drawing script and must not overwrite the new artwork.

Build 4 App Store release files remain historical snapshots with the old icon. Build 5 contains this new icon; archive build 5 or later for the next App Store upload.
